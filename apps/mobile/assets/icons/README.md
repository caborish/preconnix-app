# PreConnix interface icons

32 original SVG icons authored for this handoff. Coordinates: 24 × 24. Stroke: 1.8. Rounded ends and joins. No raster dependencies or third-party icon pack.

Navigation mapping:

Recolour the full stroke in the app. Active state: #5C3A91. Inactive state: #6B5E7B. Navigation combines the icon, visible text label and a light violet selection capsule. Use a minimum 48 × 48 touch area even when the visible icon is smaller.

Utility icons include chevron, check, clock, play, bookmark, bell, shield, lock, edit, help, heart, clipboard, message, plus, search, more, calendar, download and logout. Learn lesson icons (4 Nov 2026): sprout, stethoscope, pill, apple, ban, pulse, smile and people.

These are interface symbols. The brand's multicolour petal mark lives in `../brand/` and should not replace functional navigation icons.
